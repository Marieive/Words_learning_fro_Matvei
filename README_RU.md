# Сайт для повторения слов Матвея

## Перед загрузкой на GitHub Pages

1. В Google Sheets опубликуй лист `Words` как CSV и скопируй ссылку.
2. Открой `config.js` и вставь эту ссылку в `WORDS_CSV_URL` вместо `PASTE_PUBLISHED_WORDS_CSV_URL`.
3. Адрес готового Apps Script уже указан в `RESULTS_ENDPOINT` — его менять не нужно.
4. Если используешь цель недели из отдельного листа, опубликуй его как CSV и вставь ссылку в `GOAL_CSV_URL`. Иначе оставь значение как есть.

В первой строке листа слов должны быть колонки `id`, `en`, `ru`, `lesson`, `category`, `example`, `active`, `Чанк`. `id` должен быть постоянным и уникальным. В упражнения попадают только строки, где `active=TRUE`.

## Загрузка на GitHub Pages

Загрузи `index.html`, `style.css`, `app.js`, `config.js` и `sw.js` в корень репозитория сайта, сохрани изменения и включи GitHub Pages в настройках репозитория. Открывай сайт по HTTPS-ссылке Pages. После первого открытия онлайн сайт сохранит оболочку и слова на устройстве для работы без сети.

`WORDS_CSV_URL` читает слова из таблицы. `RESULTS_ENDPOINT` уже указывает на готовый Apps Script, который принимает итоги занятий.
